# Security policy

Security fixes target the current release. Use the latest published version of `@drod915/kvdiff`.

## Reporting a vulnerability

Contact the maintainer privately at [@drod915 on X](https://x.com/drod915). If you cannot send a direct message, [open a GitHub issue](https://github.com/flipcyde101/kvdiff/issues/new) requesting a private reporting channel. Keep vulnerability details out of the public issue.

In your private report, include the affected version, the impact, and steps to reproduce using sanitized data. Remove API keys, authorization headers, and private prompts from any examples.
